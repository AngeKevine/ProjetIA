# ProjetIA

#  PROJET EN RESUME

#  Transport de matériaux par des robots autonomes

Deux robots autonomes doivent collecter des matériaux dans un entrepôt et les déposer dans une zone de 
livraison. Chaque matériau possède un poids et chaque robot une capacité maximale. Le projet combine 
recherche heuristique (RH), satisfaction de contraintes (CSP), logique de programmation (LP) et systèmes 
multiagents (SMA).
